# FreedomMusic

一个基于 React + TypeScript 的现代化音乐播放器 Web 应用，对接网易云音乐 API，提供沉浸式的音乐体验。

## 功能特性

### 核心播放
- 歌曲播放、暂停、上一首、下一首
- 播放队列管理（待播放歌曲列表）
- 播放模式切换（顺序、随机、单曲循环、列表循环）
- 播放速度调节（0.5x ~ 2x）
- 进度条拖拽seek
- 音量控制
- 睡眠定时器
- 全屏播放器（歌词+封面）
- **URL预加载缓存**：切歌秒播，无需等待网络请求

### 音乐库
- 个性化推荐歌单
- 排行榜（支持搜索、滚动加载）
- 歌单详情页（支持分批加载歌曲）
- 搜索功能（综合、单曲、歌单、专辑、歌手）
- 歌手/专辑详情页

### 定制歌单（Daily Flow）
- 三种心情模式：开心、平静、伤心
- 每种心情7张背景图，按星期轮换
- 心情选择器（旋转式交互）
- 自动匹配心情主题色

### 用户系统
- 二维码扫码登录
- 用户歌单管理（创建、删除、添加歌曲）
- 本地歌单存储（服务端JSON文件）
- 播放历史记录

### 设置
- 主题切换（8种预设主题 + 自定义颜色）
- 玻璃面板透明度调节
- 存储管理（数据目录、容量限制）
- 天气地区选择（下拉选择城市）
- 心情跟随主题开关

### 性能优化
- 所有主要数据磁盘缓存（7天自动清理）
- 排行榜启动时后台预加载全部榜单
- 音频预加载池（Audio元素池，切歌秒播）
- Banner背景图启动时预加载
- 搜索结果缓存
- 歌手/专辑详情缓存

## 技术栈

| 技术 | 用途 |
|------|------|
| React 19 | UI框架 |
| TypeScript | 类型安全 |
| Vite 8 | 构建工具 |
| Tailwind CSS 4 | 样式系统 |
| React Router 7 | 路由管理 |
| Axios | HTTP请求 |
| FontAwesome | 图标库 |
| NeteaseCloudMusicApi | 后端API代理 |
| Express | 后端服务 |

## 项目结构

```
FreedomMusic/
├── server.cjs              # Express后端服务（API代理、缓存、用户歌单）
├── src/
│   ├── components/         # 公共组件（Header、Sidebar、搜索栏等）
│   ├── context/            # React Context（播放器、数据、认证、心情）
│   ├── features/           # 功能模块
│   │   ├── auth/           # 登录认证
│   │   ├── discover/       # 发现页（Banner、推荐、每日随机）
│   │   ├── leaderboard/    # 排行榜
│   │   ├── library/        # 音乐库（歌手/专辑详情）
│   │   ├── player/         # 播放器（全屏、歌词、均衡器）
│   │   ├── playlist/       # 歌单管理
│   │   ├── search/         # 搜索
│   │   └── settings/       # 设置页
│   ├── hooks/              # 自定义Hook
│   ├── services/           # API服务层
│   ├── styles/             # 全局样式（主题、玻璃效果）
│   └── utils/              # 工具函数（缓存、格式化、天气）
├── public/                 # 静态资源（图标、天气数据）
└── backup/                 # 项目备份
```

## 快速开始

### 环境要求
- Node.js >= 18
- npm 或 yarn

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

同时启动前端（Vite）和后端（Express），访问 http://localhost:5173

### 单独启动后端

```bash
npm run server
```

后端运行在 http://localhost:3000

### 构建生产版本

```bash
npm run build
```

## 数据存储

应用使用多层缓存策略：

| 数据类型 | 存储位置 | 过期策略 |
|----------|----------|----------|
| 首页推荐歌单 | 服务端磁盘 | 7天 |
| 排行榜列表 | 服务端磁盘 | 7天 |
| 排行榜歌曲 | 服务端磁盘 | 7天 |
| 歌单详情 | 服务端磁盘 | 7天 |
| 搜索结果 | 服务端磁盘 | 7天 |
| 歌手/专辑 | 服务端磁盘 | 7天 |
| 用户歌单 | 服务端JSON文件 | 永久 |
| 播放状态 | 前端Config | 永久 |
| 用户歌单(前端) | localStorage | 永久 |

## 主题系统

内置8种主题：Midnight、Aurora、Obsidian、Rose、Forest、天蓝、薄荷、深夜

支持自定义主题颜色（背景渐变 + 强调色），通过CSS变量实现全局主题切换。
